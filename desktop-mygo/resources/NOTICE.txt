This is a fork

This is a modified fork of TextFold, originally created by Xia Chen
(https://github.com/chenxiachan/textfold), maintained by cjdem
(https://github.com/cjdem/textfold). This fork is not affiliated with or endorsed by the
original author.

Changes in this fork:

- Windows only: the desktop app and its build targets.
- The Electron desktop shell was replaced by a Go/MyGo shell.
- Every PDF and picture is converted through MinerU Cloud API; the local MinerU engine and
  the offline PDF path were removed.
- The desktop app updates from this fork's signed release feed.
