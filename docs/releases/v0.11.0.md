# TextFold 0.11.0

Windows 10 and 11, 64-bit. The app updates itself; a copy installed before the MyGo switch needs one manual
reinstall. The installer is not code-signed, so SmartScreen may ask once.

## PDFs and pictures

- Every PDF and picture is read by MinerU's Cloud API; set the key in Settings. The file leaves this computer for
  conversion.
- A connection lost while MinerU reads a PDF no longer starts over: importing the same file again continues the same
  batch; a new batch is submitted only when the service no longer has the task or the batch never received the file.
- A scan with no text is read once more with OCR, and that pass has its own resume.

## A steadier library

- Notes, reading cards and the Zotero index take a cross-process lock for every save, and library files are written
  whole or not at all. A note or card save, a generation, a re-conversion and a move to the trash cannot overwrite each
  other, and a deleted document is not recreated by a late save or conversion.
- A stored English layer is trusted per unit: a re-parsed paragraph is read local and the layer is marked stale.

## The reader

- The Aa menu sets size, width and font; light or dark, a paper style, line spacing; focus (F); the place you left is
  kept.
- A pinned sidebar, margins, a heading scale, and the Topic map.
- The whole-paper note sits in the Topic map's left column and opens beside its card; a note draft keeps its words
  when it closes.

## The library

- Nested folders, multi-select, a ten-second Undo, and names for documents.
- The whole text exports as Markdown at the level being read, in the language being read.

## The app

- The MyGo shell with a bundled Python; the Anthropic SDK is included, so Settings can offer the Anthropic API.
- API providers, OpenRouter, and a running local Magpie gateway; the ChatGPT bridge is gone.

## 中文

Windows 10/11（64 位）。已装 0.10.7 的 App 会自己更新；更早的 Electron 版需要手动重装一次。

- PDF 和图片只走 MinerU Cloud API；密钥在设置里填，文件会离开电脑转换。读 PDF 时断线不会从头上传，重新导入同一份文件会继续原来的批次；只有任务不存在、或批次确认没收到文件时才新建批次。
- 笔记、阅读卡和 Zotero 索引的保存跨进程加锁，文献库整份写入；笔记和阅读卡的保存、生成、重新转换和移入回收站不会互相覆盖。
- Aa 菜单、明暗和纸张样式、行距、专注（F）、离开位置、固定侧栏、页边距、标题层级、Topic 地图；文献库支持嵌套文件夹、多选、10 秒撤销和命名；整篇笔记在 Topic 地图左栏；按当前层级导出 Markdown。
